# administracionNH

Este repositorio contiene dos proyectos independientes.

## 1. Página de valores — Mis Manitos Nahuel Huapi

Sitio estático con los valores y servicios del jardín. Vive en la **raíz** del repositorio
(`index.html`, `style.css`, `script.js`, `valores.js`).

Para modificar precios y textos: ver **[INSTRUCCIONES.md](./INSTRUCCIONES.md)**.

## 2. Dashboard Comercial — Gerencia Zonal (Sancor Salud)

Aplicación web que reemplaza el uso diario de la planilla de gestión comercial: ventas,
objetivos, bajas y prospectos del equipo de asesores, con login por rol (gerente / vendedor)
y Google Sheets como base de datos en vivo.

Está en la carpeta **[`sancor-dashboard/`](./sancor-dashboard)**.

- Qué hace y cómo está armado: [`sancor-dashboard/README.md`](./sancor-dashboard/README.md)
- Cómo conectarlo a tu planilla, paso a paso:
  [`sancor-dashboard/GUIA-DE-CONFIGURACION.md`](./sancor-dashboard/GUIA-DE-CONFIGURACION.md)
